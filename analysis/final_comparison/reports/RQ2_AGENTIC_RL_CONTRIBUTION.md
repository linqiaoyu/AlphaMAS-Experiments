# RQ2 — Agentic RL Contribution

## Evidence

With the information environment held fixed, M2 reduced aggregate cumulative return by 14.48 percentage points relative to M1 (16.39% to 1.91%). Sharpe changed by -2.664; MDD increased by 0.05 percentage points; Calmar changed by -7.293. Average exposure fell from 40.52% to 27.73%, while turnover rose from 1.320 to 1.664, trades rose from 4 to 5, and cost rose by $85.20.

Stock return deltas were AAPL -29.09 percentage points, AMZN +0.09 percentage points, and JPM -14.46 percentage points. Only AMZN improved, marginally. AAPL never entered the market; JPM lost 0.96%.

## Answer

The complete Agentic RL Trader did not improve the frozen system economically. It materially changed behaviour—lower aggregate participation but higher switching intensity and cost—and produced worse aggregate return and risk-adjusted performance. This is a correctness-valid negative result, not an implementation failure: every M2 audit passed and PM-to-execution mapping was consistent in all 78 decisions.

# M1 FinMultiTime input freeze

This directory contains the corrected, pre-formal M1 FinMultiTime input
bundle. The frozen inputs are under `inputs/`; the source-integrity erratum is
documented in [M1_INPUT_CORRECTNESS_ERRATUM.md](M1_INPUT_CORRECTNESS_ERRATUM.md).

Formal M1 was not run. Do not reclean the upstream FinMultiTime dataset,
regenerate captions, alter packet text, or treat this archive as a formal M1
result. Reuse the exact case, packet, image, caption, and manifest files for
later stages.

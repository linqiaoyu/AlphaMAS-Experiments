# M2 E2E_PILOT archive

This development-only archive contains the exact operational inputs and, after execution, the first complete correctness-valid trajectories for the eight frozen E2E cases. It is not a model-selection population. FINAL_HOLDOUT and Formal 2024H1 are excluded.

`preflight.json` binds the remote-verified Phase-A commits, architecture and preregistration identities, packet archive, exact market bytes, cost guards, and canonical AWS environment before the first paid call. The market snapshot contains the 252-session warmup through the terminal 2023-10-13 valuation for the eight pilot stocks plus SPY. The yfinance retrieval is used only as a frozen backtester input; it is not supplied to Agent prompts as web evidence.
